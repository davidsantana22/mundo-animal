# Estado de entrega de Mundo Animal

Revisión y publicación: 18/10/2026.

## Sitio publicado

https://davidsantana22.github.io/mundo-animal/

Repositorio completo: https://github.com/davidsantana22/mundo-animal

GitHub Pages está habilitado desde la rama `main`, carpeta raíz, con HTTPS. Se comprobó la página publicada en navegador. La cuenta y los permisos de administración se verificaron antes de cargar archivos. A pedido del usuario se renombró el repositorio vacío `VeterinariaMundoAnimal` a `mundo-animal`. El usuario autorizó expresamente el repositorio y el sitio públicos antes de subir el contenido.

## Alcance entregado

Sitio informativo estático: inicio, servicios, petshop, consejos, galería, nosotros y contacto. Incluye filtros de categorías, menú móvil, consejos desplegables, diálogo de privacidad y enlaces de contacto. Conserva el diseño cálido y nueve ilustraciones originales sin personas. Los datos de contacto y horarios se conservan según la fuente y las confirmaciones documentadas.

No incluye cuentas, pagos, expedientes ni almacenamiento de datos de mascotas. No anuncia atención de 24 horas ni presenta turnos como confirmados. La futura aplicación privada se propone en `ARQUITECTURA-PRIVADA.md` y no se implementa en GitHub Pages.

## Revisión

Se verificaron las interacciones principales y el diseño en marcos de 390, 768 y 1440 px. Se corrigió un desborde móvil de cuatro píxeles causado por la etiqueta decorativa girada y se restauró el foco al botón del menú cuando se cierra con Escape. Los recursos modificados llevan versión en su URL para evitar caché anterior. Resultados y límites en `PRUEBAS.md`.

## Control y mantenimiento

El proyecto y su historial están en la cuenta de GitHub del usuario. No se crearon contraseñas, claves de API ni cuentas adicionales. No hay servicios pagos contratados. Cambiar los archivos en `main` inicia un nuevo despliegue automático de Pages. La página `tests/responsive.html` permite repetir la inspección adaptable y no guarda datos.
