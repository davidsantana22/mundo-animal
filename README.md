# Mundo Animal

Primera versión informativa para Mundo Animal, veterinaria y petshop en Fray Bentos. HTML, CSS y JavaScript sin instalación de dependencias ni proceso de compilación.

## Abrir y mantener

Abrí `index.html` en un navegador o serví esta carpeta con un servidor estático. Los recursos y scripts usan rutas relativas, compatibles con GitHub Pages dentro de un repositorio.

- `index.html`: estructura, textos institucionales, contacto y consejos.
- `assets/css/styles.css`: colores, tipografías locales, diseño adaptable y movimiento reducido.
- `assets/js/config.js`: número de WhatsApp y saludo público. No admite secretos.
- `assets/js/content.js`: servicios y categorías editables.
- `assets/js/app.js`: renderizado, filtros, menú y privacidad.
- `assets/images`: nueve ilustraciones SVG originales, sin fotografías de personas ni recursos remotos.

## Alcance

Inicio, Servicios, Petshop, Consejos, Galería, Nosotros y Contacto. WhatsApp usa `wa.me` y abre un borrador de conversación; no envía mensajes automáticamente ni confirma turnos. El catálogo contiene categorías ilustrativas sin precios, stock ni venta en línea.

Esta versión no tiene cuentas, pagos, formularios, analítica, base de datos ni historiales clínicos. No colocar información sensible en este repositorio, en archivos JavaScript, en el navegador ni en GitHub Pages.

La fuente es el documento aportado `Mundo_Animal_Base_del_proyecto_web.docx`, recuperado de la entrega de la conversación del 17/10/2026. Contacto y horarios ratificados por el usuario el 18/10/2026. Los servicios proceden de los anuncios documentados; se pide consultar disponibilidad y alcance. No se anuncia cobertura 24 h, equipo, titulaciones, testimonios, precios, promociones ni atención de especies no acreditadas.

La marca gráfica de huella y las ilustraciones son una propuesta nueva para este proyecto; no reproducen el logotipo original. Las imágenes originales del perfil no estuvieron disponibles como adjuntos independientes; se evita reutilizar fotogramas de redes con personas, música, marcas comerciales o derechos de terceros inciertos.

No se otorga una licencia pública de reutilización de la identidad o de los contenidos comerciales. Los SVG creados para esta entrega pueden ser usados por el titular del proyecto en su sitio. Ningún recurso visual requiere atribución a terceros. Ver `docs/RECURSOS.md`.
